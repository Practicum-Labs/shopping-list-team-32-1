# Shopping List v1.0.0

Первый релиз приложения для ведения списков покупок.

## Что вошло

- Онбординг и переход к авторизационному сценарию после первого запуска.
- Регистрация, авторизация, восстановление пароля и выход из аккаунта.
- Хранение локальных списков отдельно для каждого авторизованного пользователя.
- Создание, просмотр, поиск, копирование, переименование и удаление списков покупок.
- Добавление, редактирование, удаление и отметка купленных товаров.
- Очистка купленных товаров и удаление всех товаров списка с подтверждением.
- Сортировка товаров по алфавиту и ручная сортировка через drag and drop.
- Подсказки названий товаров при добавлении нового товара.
- Светлая и темная темы приложения.
- Адаптация интерфейса под планшетный режим.

## Техническое

- UI реализован на Jetpack Compose и Material 3.
- Архитектура построена на MVVM и разделении слоев presentation, domain, data.
- Для локального хранения используется Room и DataStore.
- Для сетевого слоя используется Retrofit.
- Для dependency injection используется Koin.
- Подключены Detekt, Reviewdog, unit-тесты и Kover.
- Release-сборка собирается и подписывается через GitHub Actions.
